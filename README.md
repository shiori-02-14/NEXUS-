# NEXUS プライバシーポリシー

**最終更新日：2026年5月21日**

本間健一（以下「開発者」）は、NEXUS（以下「本アプリ」）における利用者のプライバシーを尊重し、個人情報の取り扱いについて以下のとおり定めます。

---

## 1. 収集する情報

### 1.1 アプリ内で作成・保存するデータ（ローカル・共有領域）

時間割、ToDo、GPA、出欠、カレンダー表示設定、通知設定、表示設定、時間割背景画像、PDF作成に利用した画像などのデータは主に端末内に保存されます。  
ホーム画面ウィジェット（Android ではホーム画面構成要素）表示のため、上記の一部を OS の仕組み（iOS の App グループ等、アプリと拡張機能間の共有領域）経由で拡張機能と共有する場合があります。共有されるのは表示に必要な範囲に限られます。

### 1.2 Googleアカウント同期を利用した場合

Googleでサインインしアカウント同期を有効にした場合、時間割・ToDo・GPA・出欠・お知らせ既読状態などの同期対象データが Firebase/Firestore に保存されます。  
保存先は、サインイン中ユーザーのUIDに紐づく領域です。認証状態表示のため、メールアドレスおよび表示名を本アプリ内で利用する場合があります。

### 1.3 学生プロフィール・アンケート情報

初回起動時またはプロフィール更新時に、学部・学科、学年、区分（例：学内／その他）、性別、任意のアルバイト頻度などを入力していただく場合があります。  
これらは端末内および Firebase/Firestore に保存され、サービス改善、利用傾向の把握、統計的な分析に利用します。送信時には匿名または認証用のUID、アプリバージョン、プラットフォーム、年度などのメタデータを併せて保存する場合があります。氏名・住所・電話番号など、入力フォームの項目として個人を直接特定する情報は収集しません。

### 1.4 UEC Review

UEC Reviewを利用する場合、電気通信大学のGoogleアカウントによる認証のため、メールアドレス、表示名、Firebase UIDを取得します。  
投稿された授業評価、コメント、履修時期、任意で添付した学科・学年などの投稿者プロフィールは、本機能の利用者に公開されます。通報を行った場合、通報対象、理由、通報者UID、作成日時を保存します。

### 1.5 天気情報・シラバス等の外部公開データの取得

本アプリは気象庁などが公開する予報・観測データを、表示・ウィジェット更新のために取得します。取得時に利用者の現在地を送信する仕組みにはしておらず、天気表示は所定の地域（東京地方など固定エリア）に基づきます。  
シラバス、大学関連リンク、協賛・アルバイト情報など外部サイトを表示・取得する場合、通信先のサービスに通常のアクセス情報が送信されることがあります。  
履歴書作成の住所自動入力を利用する場合、入力された郵便番号を住所検索サービスへ送信し、都道府県・市区町村・町域などの候補を取得します。氏名、番地、建物名、電話番号などは住所検索サービスへ送信しません。

### 1.6 システム連携（権限）

- カレンダー：ToDo締切の反映・外部カレンダー表示のため、イベントの読み取り・作成を行います  
- 写真ライブラリ：時間割の背景画像、落とし物掲示板の試作投稿、PDF作成などで、利用者が選択した画像を利用します  
- カメラ：書類のスキャンや画像選択機能で、利用者が撮影・選択した内容を利用します  
- 通知：ToDo・出欠リマインダーのため、ローカル通知を送信します  
- トラッキング：広告のパーソナライズや計測のため、許可された場合に広告識別子（iOS：IDFA、Android：広告ID 等）を利用することがあります

いずれも利用者の許可を得たうえで行います。

---

## 2. 広告について（AdMob）

本アプリでは Google AdMob により広告を表示しています。広告表示時、デバイス情報、広告表示・クリック情報、IPアドレス、広告識別子等が Google に送信される場合があります。広告識別子の利用可否は OS の設定および許可状態に従います。  
詳細は [Google のプライバシーポリシー](https://policies.google.com/privacy) をご確認ください。

---

## 3. 外部サービスについて

本アプリでは、Google（AdMob / Firebase / Google Sign-In）、Apple および Google（App Store / Google Play、OS の共有コンテナ・ウィジェット、カレンダー・写真・通知等の OS 機能）、気象庁、大学・協賛先・外部 Web サイトが公開するデータ取得に用いる通信（インターネット経由）等を利用しています。  
これら外部サービス上でのデータ取り扱いは、各提供元の規約・ライセンス・プライバシーポリシーに従います。

---

## 4. データの保存期間と削除

- アプリ内データは、アプリを削除するまで端末内および同期先に保存されます  
- 「全データをリセット」を実行すると対象データは削除されます（この操作は取り消せません）  
- Googleアカウント同期を利用している場合、削除操作は同期先にも反映される場合があります  
- UEC Reviewの投稿、通報、学生プロフィール・アンケート送信データなどサーバー側で管理される情報については、必要に応じてお問い合わせください

---

## 5. 第三者への提供

開発者は、利用者の同意がある場合、法令に基づく場合、または生命・身体・財産の保護のために必要な場合を除き、個人情報を第三者へ提供しません。

---

## 6. 安全管理

開発者は、取得した情報について、不正アクセス、紛失、改ざん、漏えい等を防止するため、利用目的に応じて合理的な安全管理に努めます。
