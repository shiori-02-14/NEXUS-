# NEXUS プライバシーポリシー

**最終更新日：2025年2月**

しおり（以下「開発者」）は、NEXUS（以下「本アプリ」）における利用者のプライバシーを尊重し、個人情報の取り扱いについて以下のとおり定めます。

---

## 1. 収集する情報

本アプリは、以下の情報を収集・利用します。

### 1.1 アプリ内で作成・保存するデータ（ローカルおよびiCloud）

| データ種類 | 内容 | 保存先 |
|------------|------|--------|
| 時間割データ | 授業名、教室、講師、曜日・時限など | 端末内 / iCloud（有効時） |
| ToDoデータ | タスク名、締切日、メモ、通知設定など | 端末内 / iCloud（有効時） |
| GPAデータ | 科目名、単位、成績など | 端末内 / iCloud（有効時） |
| アプリ設定 | 通知ON/OFF、表示設定、出欠通知設定など | 端末内 / iCloud（有効時） |
| 購入状態 | 広告非表示などの購入済みかどうか | 端末内（UserDefaults） |

これらのデータは**開発者のサーバーには送信されません**。端末内およびお使いのiCloudアカウント内のみで管理されます。

### 1.2 システム連携によりアクセスするデータ

| 機能 | アクセスするデータ | 利用目的 |
|------|-------------------|----------|
| カレンダー連携 | 端末のカレンダー（イベントの読み取り・作成） | ToDo締切のカレンダー反映、外部カレンダー表示 |
| 写真ライブラリ | 選択した画像のみ | 時間割の背景画像として使用 |
| 通知 | ローカル通知の送信 | ToDoリマインダー、出欠入力リマインダー |

カレンダー・写真へのアクセスは、いずれも利用者の許可を取得したうえで行います。

---

## 2. 広告について（AdMob）

本アプリでは、Google が提供する AdMob により広告を表示しています。広告表示時、以下の情報が Google に送信される場合があります。

- デバイス情報（OS、言語、識別子など）
- 広告の表示・クリックに関する情報
- IPアドレス（概算地域の推定に使用される場合があります）

詳細は [Google のプライバシーポリシー](https://policies.google.com/privacy) をご確認ください。  
広告のパーソナライズを制限したい場合は、端末の「設定」→「プライバシー」から広告識別子（IDFA）のリセットや制限が可能です。

---

## 3. 課金（App Store / In-App Purchase）について

広告非表示や応援プランなどの課金は、Apple の App Store を通じて処理されます。  
決済に必要な情報（クレジットカード番号など）は開発者に渡されず、Apple が管理します。詳細は [Apple のプライバシーポリシー](https://www.apple.com/jp/legal/privacy/) をご覧ください。

---

## 4. iCloud 同期について

本アプリでは、iCloud を利用したデータ同期機能を提供しています。

- iCloud を有効にした場合、時間割・ToDo・GPA などのデータは、お使いの Apple ID に紐づく iCloud アカウントに保存されます。
- 同じ Apple ID でログインした複数の端末間でデータが同期されます。
- iCloud のデータ取り扱いについては、[Apple の iCloud 利用規約およびプライバシーポリシー](https://www.apple.com/jp/legal/privacy/) が適用されます。

---

## 5. データの保存期間と削除

- **アプリ内データ**：アプリを削除するまで端末および iCloud に保存されます。
- **「全データをリセット」**：設定画面の操作で、時間割・ToDo・GPA のデータを削除できます。この操作は取り消せません。
- アプリ削除後、端末上のデータは消去されます。iCloud に同期されたデータは、iCloud の設定に従って管理・削除できます。

---

## 6. 第三者への提供

開発者は、以下の場合を除き、利用者の個人情報を第三者に提供しません。

- 利用者の同意がある場合
- 法令に基づく開示要求がある場合
- 人の生命・身体・財産の保護のために必要な場合

なお、広告配信（AdMob）、課金（Apple）、iCloud 同期については、それぞれ Google および Apple のサービス・ポリシーが適用されます。
